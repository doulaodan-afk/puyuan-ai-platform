# 「濮院毛衫」产业AI赋能平台：MVP迭代看板（可开工版）

**版本**：V1.0  
**日期**：2026-05-18  
**目标上线日**：2026-08-20

---

## 1. 迭代节奏

- 迭代长度：2周/迭代。
- 会议节奏：每日站会（15分钟），每周评审（60分钟），双周复盘（90分钟）。
- 看板列：`Backlog -> Ready -> In Progress -> QA -> UAT -> Done`。

---

## 2. P0（开工与底座）2026-05-20 ~ 2026-06-16

## 2.1 目标
- 完成基础工程能力与计费主链路最小闭环。

## 2.2 Backlog
- [ ] 项目仓库初始化与分支保护规则。
- [ ] CI流水线（构建、单测、静态检查）。
- [ ] 身份认证、租户、角色权限（RBAC）。
- [ ] 账户钱包、账本、幂等记录、充值订单。
- [ ] 余额查询与消费明细接口。

## 2.3 验收门禁
- `登录 -> 查询余额 -> 创建充值单 -> 到账入账` 端到端可跑通。
- 同一 `Idempotency-Key` 重试不重复入账/扣费。
- 核心服务日志可按 `request_id` 全链路追踪。

---

## 3. P1（插件与业务）2026-06-17 ~ 2026-07-21

## 3.1 目标
- 两个核心插件可用，商家端与管理端具备最小可运营能力。

## 3.2 Backlog
- [ ] 插件注册、上架、启用/禁用能力。
- [ ] 统一调用接口 `/plugins/{plugin_id}/invoke`。
- [ ] AI商品图插件V1（页面、参数、任务、结果回显）。
- [ ] AI视频脚本插件V1（输入、生成、导出）。
- [ ] 管理后台：租户管理、插件管理、价格配置。

## 3.3 验收门禁
- 两个插件均可独立调用并回写账本。
- 商家可在工作台启用插件并直接使用。
- 管理员可完成插件上架与灰度发布。

---

## 4. P2（稳定性与上线）2026-07-22 ~ 2026-08-20

## 4.1 目标
- 完成安全合规、账单对账、压测与UAT，具备试运营条件。

## 4.2 Backlog
- [ ] 日账单/月账单生成与导出。
- [ ] 对账重跑工具与异常工单流程。
- [ ] 内容安全审核链路（文本/图片）与审计日志。
- [ ] 压测与性能优化（高峰并发、慢SQL治理）。
- [ ] UAT测试、上线演练、应急预案。

## 4.3 验收门禁
- 计费准确率 `>=99.9%`，零重复扣费事故。
- 插件调用成功率 `>=97%`，核心接口错误率 `<1%`。
- 10家试点商家完成全流程并通过验收。

---

## 5. 跨迭代“长期进行中”事项
