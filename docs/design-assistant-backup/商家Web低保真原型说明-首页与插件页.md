# 「濮院毛衫」产业AI赋能平台：商家Web低保真原型说明（首页与插件页）

**版本**：V1.0  
**日期**：2026-05-18  
**范围**：`/dashboard`、`/plugins/ai-image`、`/plugins/ai-script`

---

## 1. 设计目标（MVP）

- 让商家在30秒内看懂“当前余额、可用插件、下一步操作”。
- 把主链路压缩到3步：`进入页面 -> 输入参数 -> 生成结果`。
- 对“扣费”保持透明：每次调用前可见预估消耗，调用后可见实际消耗。

---

## 2. 页面一：工作台首页（`/dashboard`）

## 2.1 页面结构（低保真）

```text
+----------------------------------------------------------------------------------+
| 顶部导航：Logo | 工作台 | 应用市场 | 账单中心 | 账户 | 用户菜单                   |
+----------------------------------------------------------------------------------+
| 左侧菜单                                                                      |
| - 工作台                                                                       |
| - 应用市场                                                                     |
| - 账户余额                                                                     |
| - 消费明细                                                                     |
| - 账单中心                                                                     |
+-----------------------------------+----------------------------------------------+
| 余额卡片区                        | 快捷操作区                                   |
| - Token余额                       | [去充值] [查看明细] [下载月账单]            |
| - 存储使用/剩余                   |                                              |
| - 近7日消耗趋势（迷你图）         |                                              |
+-----------------------------------+----------------------------------------------+
| 常用插件（卡片）                                                                  |
| [AI商品图生成] [AI视频脚本生成] [跨境翻译(预告)]                                 |
| 每张卡片：状态(已启用/未启用) + 预估单次消耗 + 进入按钮                           |
+----------------------------------------------------------------------------------+
| 最近任务列表（时间、插件、状态、token消耗、查看结果）                              |
+----------------------------------------------------------------------------------+
```

## 2.2 关键组件与字段

- `BalanceCard`
  - 字段：`token_balance`、`storage_used_gb`、`storage_free_quota_gb`
  - 操作：`去充值`、`查看明细`
- `PluginQuickCard`
  - 字段：`plugin_id`、`name`、`enabled`、`default_token_cost`
  - 操作：`立即使用`/`启用`
- `RecentTaskTable`
  - 字段：`request_id`、`plugin_name`、`status`、`token_used`、`created_at`

## 2.3 交互规则

- 当 `token_balance` 低于阈值时显示黄色告警条：`余额不足，建议立即充值`。
- 未启用插件点击“立即使用”先弹窗确认启用，再跳转插件页。
- 最近任务状态分为：`处理中`、`成功`、`失败`，失败可一键重试（带幂等键）。

## 3. 页面二：AI商品图插件页（`/plugins/ai-image`）

## 3.1 页面结构（低保真）

```text
+----------------------------------------------------------------------------------+
| 面包屑：工作台 / AI商品图生成                                                    |
+----------------------------------------------------------------------------------+
| 左栏：输入区                                 | 右栏：结果区                        |
| 1. 上传服装图（拖拽/点击）                   | 默认态：展示示例图和使用说明         |
| 2. 模特类型（女/男/童）                      | 生成中：骨架屏+进度提示              |
| 3. 场景（室内/街拍/纯背景）                   | 成功：多图网格，支持下载/复制链接     |
| 4. 风格（自然/电商/高级感）                   | 失败：错误原因+重试按钮              |
| 5. 数量（1/2/4）                              |                                      |
| [预估消耗：xxx token] [开始生成]              |                                      |
+----------------------------------------------------------------------------------+
| 底部：调用记录（时间、参数摘要、token_used、状态）                                 |
+----------------------------------------------------------------------------------+
```

## 3.2 状态机

- `idle`：初始态，按钮禁用直到上传图片。
- `ready`：参数合法，允许提交。
- `running`：请求发送成功，轮询任务状态。
- `success`：显示结果并记录实际token。
- `error`：显示失败原因，支持保留参数重试。

## 3.3 交互细节

- 提交前展示“预估Token消耗”；提交后返回“实际Token消耗”。
- 图片上传限制：`jpg/png/webp`，单张 `<=10MB`。
- 防重复提交：按钮点击后立刻置灰，前端生成 `Idempotency-Key`。

## 4. 页面三：AI视频脚本插件页（`/plugins/ai-script`）

## 4.1 页面结构（低保真）

```text
+----------------------------------------------------------------------------------+
| 面包屑：工作台 / AI视频脚本生成                                                   |
+----------------------------------------------------------------------------------+
| 左栏：输入区                                 | 右栏：输出区                        |
| 1. 商品信息（链接或文本描述）                 | 输出结构：                           |
| 2. 平台选择（抖音/快手/视频号）               | - 标题建议(3条)                      |
| 3. 风格（带货/种草/测评）                     | - 分镜脚本(按秒)                     |
| 4. 时长（15s/30s/60s）                        | - 口播文案                           |
| 5. 目标人群（可选）                           | - 关键词标签                         |
| [预估消耗：xxx token] [生成脚本]              | [复制] [导出txt]                     |
+----------------------------------------------------------------------------------+
| 历史版本（按时间倒序）                                                            |
+----------------------------------------------------------------------------------+
```

## 4.2 交互细节

- 输入商品链接时，先尝试解析标题与卖点，失败则回退纯文本输入。
- 输出支持“二次优化”按钮（基于上一版继续改写）。
- 导出时默认命名：`脚本_yyyyMMdd_HHmm.txt`。

---

## 5. 页面级异常文案（建议）

- 余额不足：`当前余额不足，完成充值后可继续生成。`
- 服务繁忙：`当前请求较多，请稍后重试。`
- 风险拦截：`内容触发安全策略，已拦截处理。`
- 上传失败：`文件上传失败，请检查网络或更换图片重试。`

---

## 6. 埋点与数据回传

- 页面曝光：`dashboard_view`、`plugin_page_view`。
- 行为埋点：`plugin_enable_click`、`invoke_submit`、`invoke_success`、`invoke_fail`。
- 业务埋点：`token_estimated`、`token_actual`、`recharge_click`。
- 目标：形成“从访问到付费”的转化漏斗，支持周复盘。

---

## 7. 验收清单（设计与开发）

1. 页面结构与信息层级符合低保真说明。  
2. 主链路可在3步内完成首次调用。  
3. 调用前后Token信息展示一致且可追溯。  
4. 异常状态均有可执行下一步（重试/充值/联系支持）。  
5. 首页和插件页在 `1366px` 与 `375px`（H5适配）布局不崩。
