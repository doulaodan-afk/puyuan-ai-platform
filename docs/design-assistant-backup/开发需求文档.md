## 1. 项目背景与目标

### 1.1 背景
项目发起方在濮院毛衫产业带深耕十余年，拥有抖音、淘宝、快手、视频号等多平台产业带服务商经验，并持有第9类“濮院毛衫”注册商标。当前AI技术爆发，计划为产业带商家提供免费、易用的AI工具集，通过Token消耗代理和数据变现构建商业模式。

### 1.2 核心目标
- 打造一个多租户SaaS平台，为濮院毛衫产业带商家提供 **零门槛AI工具**（商品图生成、视频脚本、跨境翻译等）。  
- 平台基础功能免费，按**Token消耗、存储空间、API调用次数**后付费（预充值模式）。  
- 支持**动态插件化应用管理**：管理员可随时上架/下架新的AI应用，商家端自动可见、一键启用。  
- 沉淀产业数据，未来实现数据变现（趋势报告、爆款预测等）。

## 2. 产品定位与核心概念

### 2.1 比喻模型：房东 - 租户
| 角色 | 比喻 | 技术映射 |
|------|------|----------|
| 平台方 | 房东 | 资源池化（计算/存储/AI模型）、计量计费、数据湖管理 |
| Token消耗 | 电费 | 按实际调用AI模型消耗的Token计费 |

### 2.2 品牌与商标使用

## 3. 系统架构

### 3.1 整体架构图（文字描述）
```
[商家端] → Web/小程序/H5
    ↓
API网关（鉴权 + 计量拦截器）
    ↓
[插件注册中心] ←→ [AI插件1：商品图生成]
                  [AI插件2：视频生成]
                  [AI插件3：跨境翻译]
                  [AI插件4：虚拟试衣]  （动态增删）
    ↓
模型厂商API（OpenAI、阿里、字节等）  ←  Token代理批量采购
    ↓
[计量计费系统] → [预充值账户] → [账单/报表]
    ↓
[对象存储（OSS）] 每个租户独立bucket
    ↓
[数据湖 + 分析服务] → 脱敏后输出数据产品
```

### 3.2 核心流程（开发视角）
1. 商家登录 → 前端展示已启用的插件列表（来自应用市场）。  
2. 点击使用某AI插件 → 前端调用`/v1/plugins/{plugin_id}/invoke`。  
3. API网关验证租户权限、余额，通过后路由到对应插件微服务。  
4. 插件服务调用后端大模型API，消耗Token → 返回结果。  
5. 异步记录：Token用量、存储增量、调用次数 → 更新租户余额。  
6. 每日/月生成账单，余额不足时预警。

## 4. 核心功能需求

### 4.1 商家端功能
- **注册/登录**：手机号或微信授权，自动分配`tenant_id`。  
- **工作台**：展示所有已上架插件，未启用的显示“启用”按钮，已启用的直接使用。  
- **预充值账户**：支持余额查询、充值记录、消费明细。  
- **应用市场**：浏览可用的AI插件，一键启用/禁用。  
- **简单配置**：部分插件支持首次使用时一次性配置（如默认翻译语言）。  
- **数据看板**：展示Token消耗趋势、存储使用量、各插件调用统计。

### 4.2 平台管理端功能
- **插件管理**：  
  - 上架新插件：上传`manifest.json`（含插件ID、名称、版本、描述、图标、计费类型、前端入口URL、API端点）。  
  - 下架/编辑/可见范围设置（全体会员或特定等级）。  
  - 灰度发布（可选）。  
- **租户管理**：查看所有商家，冻结/解冻，设置特殊配额。  
- **计费配置**：Token单价、存储单价、免费配额额度。  
- **账单系统**：生成商家月账单，导出报表。  
- **数据看板**：平台总调用量、总Token消耗、充值总额、插件热度排行。

### 4.3 预置AI插件（第一期MVP）
建议优先开发以下2-3个插件，验证模式：  
1. **AI商品图生成**：上传平铺服装图 → 选择模特、场景 → 生成多张模特上身图。  
2. **AI视频脚本生成**：输入商品链接或描述 → 生成短视频带货脚本（含分镜、文案）。  
3. **跨境翻译+文案优化**：商品信息自动翻译成英语/东南亚语种，适配当地文化。

后续可扩展：AI虚拟试衣、AI直播数字人、面料成分识别等。

## 5. 插件化架构技术规范

### 5.1 插件描述文件示例（manifest.json）
```json
{
  "plugin_id": "ai_image_gen_v1",
  "name": "AI商品图生成",
  "version": "1.0.0",
  "description": "上传平铺图，生成模特上身图",
  "icon_url": "https://platform.com/icons/ai_image.png",
  "billing_type": "token",   // token / 按次 / 免费
  "default_token_cost": 500,  // 每次调用预估消耗Token数（仅供参考）
  "frontend_entry": "/plugins/ai_image_gen/index.html",
  "backend_api": "http://plugin-ai-image-svc/api/generate",
  "need_config": false,
  "config_schema": null,      // 如果需要配置，提供JSON Schema
  "visible_to": "all"         // all / vip_only / custom_list
}
```

### 5.2 前端扩展点
- 商家工作台预留扩展点：`<div id="plugin-container">`  
- 当商家启用某个插件时，前端动态加载`frontend_entry`指定的微前端模块（推荐`qiankun`或`Module Federation`）。  
- 插件与主应用通过`postMessage`通信，传递租户ID和调用参数。

### 5.3 后端服务注册
- 每个插件独立部署为微服务（或函数计算）。  
- 启动时自动注册到服务发现中心（Consul/Nacos），注册元数据包含`plugin_id`、版本、健康检查端点。  
- API网关根据请求路径中的`plugin_id`动态路由到对应实例。

### 5.4 统一调用API
```
POST /api/v1/plugins/{plugin_id}/invoke
Headers: X-Tenant-Id: xxx, X-Api-Key: xxx
Body: 插件自定义参数（JSON）
Response: {
  "code": 0,
  "data": {...},
  "token_used": 450,
  "balance_remaining": 12300
}
```

## 6. 计量计费模型

### 6.1 计费单元
| 资源类型 | 计费单位 | 说明 |
|---------|---------|------|
| Token消耗 | 千tokens | 所有AI模型调用统一折算成Token（按模型厂商标准） |
| 存储空间 | GB/月 | 每个租户OSS存储量，超出免费配额后计费 |
| API调用次数（可选） | 千次 | 非Token类简单API，如查询天气等 |

### 6.2 免费配额（每个租户每月）
- Token：10万（约可生成200张AI商品图或500次翻译）  
- 存储：5GB

### 6.3 充值定价建议
| 充值档位 | 获得Token（万） | 赠送比例 | 有效期 |
|---------|---------------|---------|--------|
| 50元     | 10            | 0%      | 1年    |
| 200元    | 45            | 12.5%   | 1年    |
| 500元    | 120           | 20%     | 2年    |
| 2000元   | 500           | 25%     | 2年    |

存储超额部分：0.5元/GB/月

### 6.4 平台盈利模式
- **Token代理价差**：从模型厂商批量采购（如GPT-4o 批量价￥0.8/千tokens），零售价￥1.2/千tokens，毛利约33%。  
- **存储与增值服务**（后期）：定制数据分析报告、爆款预测API调用。  
- **品牌授权费**（可选）：为优质商家提供“濮院毛衫认证”子品牌，收取年费或销售分成。

## 7. 开发路线图与预算

### 7.1 分阶段规划

| 阶段 | 周期 | 交付内容 | 开发预算 |
|------|------|----------|----------|
| **MVP** | 3个月 | 多租户基础 + 2个AI插件 + 充值/计费系统 + 简易管理后台 | 8-12万元 |
| **V1.0** | 后续3个月（累计6个月） | 完善插件化架构（应用市场）、新增2个插件、前端微前端改造、数据看板 | 15-20万元 |
| **V2.0** | 第2年 | 数据湖建设+趋势报告系统、对接跨境电商平台、高并发优化 | 20-30万元 |

### 7.2 每年运维成本估算
- 服务器/OSS：根据用户量，初期约2-5万元/年  
- 第三方API采购：按实际用量，可先预充值5万元作为启动Token池  
- 开发迭代：至少保留5-10万元/年用于功能优化和安全加固

## 8. 技术选型建议（供参考）

| 层面 | 推荐技术栈 | 说明 |
|------|-----------|------|
| 后端框架 | Spring Boot / Go + Gin | 高并发、易扩展 |
| API网关 | Kong / APISIX / Nginx + Lua | 支持动态路由、限流、鉴权 |
| 服务发现 | Consul / Nacos | 插件动态注册 |
| 计量计费 | 自研 + Redis（计数器） + 定时任务（账单） | 需保证精度，支持扣费回滚 |
| 前端 | Vue3 / React 18 + 微前端（qiankun） | 插件隔离 |
| 数据库 | MySQL（租户/订单/配置） + MongoDB（日志/调用记录） | 分库分表考虑 |
| 对象存储 | 阿里云OSS / 腾讯云COS | 兼容S3协议 |
| AI模型采购 | OpenAI、阿里通义、字节豆包、智谱等 | 可同时接入多家，动态调度 |

## 9. 风险与合规提醒

### 9.1 商标与品牌
- 第9类商标已覆盖可下载软件，但SaaS云服务建议补充注册**第42类**（科学技术服务）。  
- 避免与政府“濮院毛衫”区域公共品牌产生冲突，建议平台展示时使用 **“濮院毛衫 · AI工坊”** 等差异化名称。

### 9.2 数据安全与隐私
- 商家的商品图、销售数据属于商业秘密，须在合同中明确平台仅用于脱敏分析，不得泄露或转卖原始数据。  
- 存储和传输加密，定期安全审计。

### 9.3 模型合规
- 使用第三方大模型API时，需遵守其服务条款，不得将API用于色情、违法内容生成。  
- 建议增加内容安全过滤模块，避免商家生成违规内容导致平台被封。
